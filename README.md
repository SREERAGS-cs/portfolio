# Portfolio

Static portfolio website (plain HTML, CSS and JavaScript). Open `index.html` in a browser
or serve the folder with any static file server.

## Tests

Unit tests for `main.js` run with [Vitest](https://vitest.dev) in a jsdom environment.

```bash
npm install
npm test          # run the suite once
npm run test:watch
npm run coverage  # text + HTML coverage report for main.js
```
